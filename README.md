# ANN Projects

This repository contains two Artificial Neural Network (ANN) projects implemented using Python and PyTorch.

## 1. ANN Classification

- Dataset: Date Fruit Dataset
- Dataset File: `DateFruit_Dataset.csv`
- Model: Artificial Neural Network (ANN)
- Task: Classification
- Loss Function: Cross Entropy Loss
- Optimizer: Adam
- Epochs: 100
- Evaluation Metric: Accuracy

## 2. ANN Regression

- Dataset: Power Plant Dataset
- Dataset File: `powerplant_data.csv`
- Model: Artificial Neural Network (ANN)
- Task: Regression
- Loss Function: Mean Squared Error (MSE)
- Optimizer: Adam
- Epochs: 100
- Evaluation Metric: Training MSE and Testing MSE
